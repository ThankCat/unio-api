# 请求记录卡片时间分桶改造

## 范围

为 Console 请求记录页顶部汇总卡片提供稳定的时间分桶与展示窗能力。保持现有
请求列表、用量页、API Key 页及账务口径不变。

## 实施项

- 为请求汇总区分指标统计窗和热力条展示窗。
- 修正自然日分桶的半开区间边界，消除多一格问题。
- 让请求卡片支持小时、天以及长自定义范围所需的周/月/季度/年 bucket。
- 返回 bucket 结束边界和未来桶状态所需的数据。
- 更新请求汇总服务、Console HTTP DTO 和相关测试。
- 运行 `sqlc generate`、格式化及受影响包测试。

## 约束

- 不修改数据库 Schema。
- 不手改 sqlc 生成文件。
- 共享 timeseries 查询对现有用量页调用保持兼容；新能力只由请求卡片显式使用。
- 保留工作树中已有的无关会话亲和改动。

## 验证

- 预设范围在自然日边界、月末和当前小时均返回预期数量的 bucket。
- 统计窗总量不包含展示窗中的未来时间。
- 现有 Console 请求、用量和 HTTP 测试通过。
